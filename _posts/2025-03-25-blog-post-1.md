When you type a message on your phone, have you noticed how it suggests the next word? For example, if you type "How are", your phone might suggest "you?" This happens because your phone has learned common word patterns from millions of conversations. Similarly, in our experiment, we are training the model to recognize patterns in a sequence so it can guess what comes next—just like your phone predicts your next word. 

Sequence problems involve data where each point is dependent on previous ones, making them prevalent in:

  - Time Series Forecasting: Predicting future stock prices or weather conditions. Example: The price of a stock today is influenced by how it changed over the past weeks or months. Computers analyze these patterns to predict future prices.
  - Natural Language Processing (NLP): Tasks like speech recognition and machine translation. Example: Virtual assistants like Alexa or Siri analyze sound waves over time to understand words. If you say "Hey Al...", it predicts you're about to say "Alexa" and starts listening.
  - Signal Processing: Analyzing electrocardiogram (ECG) signals.

The order of the information and memory matters here. Imagine reading a mystery novel. If you start from the middle, you won't understand the story. You need to remember what happened before to predict what will happen next.
Similarly, computers need memory to handle sequence problems. They must store and use past data to make better predictions.
Some sequences only depend on the last few points (like remembering a phone number for a few seconds). Others require long-term memory (like understanding the plot of a long movie). Traditional models struggle with long-term dependencies because they forget earlier parts too easily.

Let's analyze the sequence problem with basic sequential data as such sine and cosine waves. 
Because of this predictable and periodic nature, sine and cosine waves are commonly used in sequence prediction problems. They are defined as:

```mathematical
    y(t)=Asin⁡(ωt+ϕ)
    y(t)=Acos⁡(ωt+ϕ)
    Where:
    A: Amplitude (peak value)
    ω: Angular frequency
    φ: Phase shift
    t: Time
```

If a sequence model can accurately predict sine waves, it can be fine-tuned to understand other time-dependent behaviors (e.g., predicting electricity demand based on past consumption).

Let's go step-by-step to implement a simple sequence prediction model using sine waves. In this example, we will use a Recurrent Neural Network (RNN), which is effective for sequence-based problems.  Unlike traditional feedforward neural networks, RNNs maintain a hidden state that allows them to retain information from previous time steps. Below, we discuss the implementation of RNN model. 


## **Architecture of RNN**

1. Input Layer:

    - Receives the data at each time step $$ x_t​ $$.
    - Example: In a sine wave, $$ x_t​ $$ is the sine value at time $$t$$.

2. Hidden State:

    - Acts as memory by summarizing past information.
    - The hidden state in an RNN is indeed conceptually similar to how sequential circuits in digital systems work, particularly flip-flops or memory elements in sequential logic.
    - Updated at each time step using the current input and the previous hidden state:

      $$ h_t = f(W_{xh} x_t + W_{hh} h_{t-1} + b_h) $$

      - $$W_{xh}$$​: Weights connecting input to hidden state.
      - $$W_{hh}$$​: Weights connecting previous hidden state to the current hidden state.
      - $$b_h$$​: Bias term.
      - f: Activation function (e.g., tanh, ReLU).

3. Output Layer:

    - Generates the output $$y_t​$$ at each time step: 

      $$ y_t = W_{hy} h_t + b_y $$

      - $$W_{hy}$$​: Weights connecting hidden state to output.
      - $$b_y$$​: Output bias.


## **Understanding RNN Model:**

### **Forward Pass of RNN:**

 Here, the mathematical equation for computing the output and the hidden state at time `t` is as follows:

  $$
  h_t = tanh(W_{xh} x_t + W_{hh} h_{t-1} + b_h) 
  $$

  $$
  y_t = W_{hy} h_t + b_y  
  $$

```python
def forward(self, x, h_prev):
    h = np.tanh(np.dot(self.Wxh, x) + np.dot(self.Whh, h_prev) + self.bh)
    y = np.dot(self.Why, h) + self.by
    return y, h
```
- **Hidden State Update (`h`)**:
  - `np.tanh(...)`: The tanh activation function is used to introduce non-linearity and limit the values between -1 and 1.
  - `np.dot(self.Wxh, x)`: Contribution from the input.
  - `np.dot(self.Whh, h_prev)`: Contribution from the previous hidden state.
  - `+ self.bh`: Adds bias to the hidden layer.

- **Output Calculation (`y`)**:
  - `np.dot(self.Why, h) + self.by`: Computes the output using the hidden state.

This function predicts an output (`y`) and updates the hidden state (`h`), allowing the model to maintain memory of previous inputs.


### **Backward Pass of RNN:**


 The **Backpropagation Through Time (BPTT)** algorithm involves computing gradients for each weight and bias in the network. Below, we discuss the mathematical formulas for each steps of backpropagation:

**1. Compute Error at Output Layer**
- The error at the output layer measures how far the predicted output (`y_pred`) is from the true output (`y_true`).
  
  $$
  \frac{\partial L}{\partial y} = \hat{y} - y
  $$

  Where:
  
  - $$\hat{y}$$ is the predicted output.
  - $$y$$ is the true label.

  

**2. Compute Gradients for Output Layer**

- The gradient of the output weights $$(W_{hy})$$ and the output bias $$(b_y)$$ are computed using the error $$ \frac{\partial L}{\partial y} $$:

  $$
  \frac{\partial L}{\partial W_{hy}} = \frac{\partial L}{\partial y} \cdot h^T
  $$
  
  $$
  \frac{\partial L}{\partial b_y} = \frac{\partial L}{\partial y}
  $$

  Where:
  - $$ h $$ is the hidden state.
  - $$ b_y $$ is the bias of the output layer.


**3. Compute Gradients for Hidden Layer**

- The gradient for the hidden state (`h`) is computed using the chain rule, backpropagating the error from the output to the hidden layer.

  $$
    \frac{\partial L}{\partial h} = W_{hy}^T \cdot \frac{\partial L}{\partial y} \cdot (1 - h^2)
  $$

  Where:
  - $$ W_{hy}^T $$ is the transposed output weight matrix.
  - $$ h $$ is the hidden state.
  - $$ (1 - h^2) $$ is the derivative of the `tanh` activation function.

**4. Compute Gradients for Input-to-Hidden and Hidden-to-Hidden Weights**

- The gradient of the input-to-hidden weights $$(W_{xh})$$, the hidden-to-hidden weights $$(W_{hh})$$, and the hidden bias $$(b_h)$$ are computed as:

  $$
    \frac{\partial L}{\partial W_{xh}} = \frac{\partial L}{\partial h} \cdot x^T
  $$
    
  $$
    \frac{\partial L}{\partial W_{hh}} = \frac{\partial L}{\partial h} \cdot h_{prev}^T
  $$
    
  $$
    \frac{\partial L}{\partial b_h} = \frac{\partial L}{\partial h}
  $$

  Where:
  - $$ x $$ is the input.
  - $$ h_{prev} $$ is the previous hidden state.
  - $$ b_h $$ is the hidden bias.

**5. Update Weights Using Gradient Descent**

- Once the gradients are computed, the weights and biases are updated using the gradient descent rule:

  $$
    W_{hy} \leftarrow W_{hy} - \eta \cdot \frac{\partial L}{\partial W_{hy}}
  $$

  $$
    W_{xh} \leftarrow W_{xh} - \eta \cdot \frac{\partial L}{\partial W_{xh}}
  $$

  $$
    W_{hh} \leftarrow W_{hh} - \eta \cdot \frac{\partial L}{\partial W_{hh}}
  $$

  $$
    b_h \leftarrow b_h - \eta \cdot \frac{\partial L}{\partial b_h}
  $$

  Where:
  - $$ \eta $$ is the learning rate.
  - $$ W_{hy} ,  W_{xh} ,  W_{hh} $$ and $$ b_h $$ are the respective weights and biases.
  - The updates subtract the learning rate scaled by the gradient, moving the parameters in the direction that minimizes the error.

These formulas represent the key steps in the backward pass of BPTT for updating weights and biases in a recurrent neural network (RNN).


```python
 def backward(self, x, y_true, y_pred, h, h_prev, learning_rate=0.001):
        # Backpropagation through time (BPTT)

        # error at output layer
        dL_dy = y_pred - y_true

        #gradients for output weights and bias
        dL_dWhy = np.dot(dL_dy, h.T)
        dL_dby = dL_dy

        #error at hidden state
        dL_dh = np.dot(self.Why.T, dL_dy) * (1 - h**2)

        #gradients for input-to-hidden weights
        dL_dWxh = np.dot(dL_dh, x.T)

        #gradients for hidden-to-hidden weights and bias
        dL_dWhh = np.dot(dL_dh, h_prev.T)
        dL_dbh = dL_dh
        
        # Update weights with gradient descent
        self.Why -= learning_rate * dL_dWhy
        self.by -= learning_rate * dL_dby
        self.Wxh -= learning_rate * dL_dWxh
        self.Whh -= learning_rate * dL_dWhh
        self.bh -= learning_rate * dL_dbh
        
        return dL_dWxh, dL_dWhh, dL_dWhy, dL_dbh, dL_dby
```

## **Understanding the SRU Model**

The SRU is a more computationally efficient alternative to traditional RNNs because it:
- Performs recurrent updates using element-wise computations instead of matrix multiplications which is used in traditional RNN models.
- Allows parallelization of computation, unlike traditional RNNs, which require sequential operations.
- Introduces a highway connection, similar to residual connections, allowing better information flow.

In this model, we have:
- A **SRUCell** that processes a single timestep.
- A **SRU layer** that stacks multiple SRUCells to process a sequence.
- A **MusicSRU model** that takes input sequences and predicts pitch, step, and duration.

### **1. Forward Pass of SRU**
---
**Step 1: Processing input through SRU layers**

The input is a sequence of shape $$ (\text{seq_len}, \text{batch_size}, \text{input_size})$$, where:
- `seq_len` = number of time steps.
- `batch_size` = number of samples processed in parallel.
- `input_size` = number of input features.

Each time step $$x_t$$ is passed through an **SRUCell**, which updates its hidden and cell states.

**Inside an SRUCell:**

For each time step $$ t $$, we compute:
1. **Compute four gates from input $$ x_t$$**:

   $$ \text{gates} = W x_t $$
   
   where $$ W $$ is a learnable weight matrix. The result is split into four components:
  
   $$ f_t, r_t, z_t, v_t = \text{gates.chunk}(4, \text{dim}=1) $$
   
   - $$ f_t $$ = forget gate.
   - $$ r_t $$ = reset gate.
   - $$ z_t $$ = candidate cell update.
   - $$ v_t $$ = input transformation (used in the highway connection).


    ```python

        class SRUCell(nn.Module):

          def __init__(self, input_size: int, hidden_size: int, dropout: float = 0.0):
              super(SRUCell, self).__init__()
              
              self.input_size = input_size
              self.hidden_size = hidden_size
              self.dropout = dropout
              
              # Initialize weights
              self.W = nn.Linear(input_size, 4 * hidden_size, bias=True)
              self.V = nn.Linear(input_size, hidden_size, bias=False)
              self.b = nn.Parameter(torch.Tensor(2 * hidden_size))
              self.dropout_layer = nn.Dropout(dropout)
              
              # Initialize parameters
              nn.init.xavier_uniform_(self.W.weight)
              nn.init.zeros_(self.W.bias)
              nn.init.xavier_uniform_(self.V.weight)
              nn.init.zeros_(self.b)

          def forward(self, x: torch.Tensor, c: Optional[torch.Tensor] = None) -> Tuple[torch.Tensor, torch.Tensor]:

              batch_size = x.size(0)
              
              if c is None:
                  c = torch.zeros(batch_size, self.hidden_size, device=x.device))
              
              # Calculate gates
              gates = self.W(x)
              f, r, z, v = gates.chunk(4, dim=1)
              
              # Apply non-linearities
              f = torch.sigmoid(f + self.b[:self.hidden_size])
              r = torch.sigmoid(r + self.b[self.hidden_size:])
              
              # Highway connection with proper dimensions
              x_highway = self.dropout_layer(x)
              x_highway = self.V(x_highway)
              
              # Update cell state
              c_next = f * c + (1 - f) * z
              
              # Calculate hidden state
              h = r * torch.tanh(c_next) + (1 - r) * x_highway
              
              return h, c_next

    ```

2. **Compute Forget and Reset Gates**:

   - The forget gate decides how much of the past cell state should be retained:
     $$
     f_t = \sigma(f_t + b_f)
     $$
   - The reset gate controls how much of the new candidate state should be used:
     $$
     r_t = \sigma(r_t + b_r)
     $$

3. **Compute the New Cell State**:

   $$
   c_t = f_t \cdot c_{t-1} + (1 - f_t) \cdot z_t
   $$

   This blends the previous memory with the new candidate state.

4. **Compute the Final Hidden State using Highway Connection**:

   $$
   h_t = r_t \cdot \tanh(c_t) + (1 - r_t) \cdot V(x_t)
   $$

   where $$ V(x_t) $$ is a transformation of the input through another linear layer.

**Step 2: Layer Processing**

- If the SRU has multiple layers, the output of one layer becomes the input for the next.
- If bidirectional, two SRUs process the input in forward and reverse directions.

```python

class SRU(nn.Module):

    def __init__(self, input_size: int, hidden_size: int, num_layers: int = 1,
                 dropout: float = 0.0, bidirectional: bool = False, layer_norm: bool = False):
        super(SRU, self).__init__()
        
        self.input_size = input_size
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        self.dropout = dropout
        self.bidirectional = bidirectional
        self.layer_norm = layer_norm
        
        # Create SRU cells
        self.cells = nn.ModuleList()
        for layer in range(num_layers):
            layer_input_size = input_size if layer == 0 else hidden_size * (2 if bidirectional else 1)
            if bidirectional:
                self.cells.append(nn.ModuleList([
                    SRUCell(layer_input_size, hidden_size, dropout),
                    SRUCell(layer_input_size, hidden_size, dropout)
                ]))
            else:
                self.cells.append(SRUCell(layer_input_size, hidden_size, dropout))
        
        # Layer normalization
        if layer_norm:
            size = hidden_size * (2 if bidirectional else 1)
            self.layer_norm_layers = nn.ModuleList([nn.LayerNorm(size) for _ in range(num_layers)])
        else:
            self.layer_norm_layers = None

    def forward(self, x: torch.Tensor, c: Optional[torch.Tensor] = None) -> Tuple[torch.Tensor, torch.Tensor]:

        seq_len, batch_size, _ = x.size()
        
        if c is None:
            c = torch.zeros(self.num_layers, batch_size, self.hidden_size, device=x.device)
        
        # Process each layer
        output = x
        new_c = []
        
        for layer in range(self.num_layers):
            layer_output = []
            cell = self.cells[layer]
            
            if self.bidirectional:
                # Forward direction
                h_forward, c_forward = cell[0](output[0], c[layer])
                layer_output.append(h_forward)
                
                # Process rest of sequence
                for t in range(1, seq_len):
                    h_forward, c_forward = cell[0](output[t], c_forward)
                    layer_output.append(h_forward)
                
                # Backward direction
                h_backward, c_backward = cell[1](output[-1], c[layer])
                backward_output = [h_backward]
                
                # Process rest of sequence
                for t in range(seq_len - 2, -1, -1):
                    h_backward, c_backward = cell[1](output[t], c_backward)
                    backward_output.append(h_backward)
                
                # Combine directions
                layer_output = torch.stack([
                    torch.cat([f, b], dim=1)
                    for f, b in zip(layer_output, reversed(backward_output))
                ])
                
                new_c.append(torch.cat([c_forward, c_backward], dim=1))
            else:
                h, c_next = cell(output[0], c[layer])
                layer_output.append(h)
                
                # Process rest of sequence
                for t in range(1, seq_len):
                    h, c_next = cell(output[t], c_next)
                    layer_output.append(h)
                
                layer_output = torch.stack(layer_output)
                new_c.append(c_next)
            
            # Apply layer normalization if enabled
            if self.layer_norm_layers is not None:
                layer_output = self.layer_norm_layers[layer](layer_output)
            
            output = layer_output
        
        return output, torch.stack(new_c)
```


### **2. Loss Functions and Their Impact on Training**
---

In our SRU-based model, a combination of loss functions was used that significantly improved the training process and the results. By customizing the loss functions, we were able to ensure that the model better captured the nuances of pitch, step, and duration in music sequence prediction.

Three distinct loss functions were used during training:

1. **Cross-Entropy Loss for Pitch Prediction**:

   - For pitch prediction, CrossEntropyLoss was employed, which is standard for classification tasks. This loss function calculates the difference between the predicted pitch and the true pitch by penalizing incorrect predictions. It allows the model to focus on accurately predicting discrete pitch classes.

2. **Mean Squared Error (MSE) with Positive Pressure for Step and Duration**:
   - For both step and duration predictions, a custom version of Mean Squared Error (MSE) called MSE with Positive Pressure was used. This custom loss function ensures that the model outputs positive values for step and duration by adding a penalty term for negative predictions.
   - The positive pressure term forces the model to only predict non-negative values, which is crucial for tasks such as predicting time durations or musical step intervals that inherently cannot be negative.
   - The MSE component ensures that the model's predictions are as close as possible to the ground truth, while the positive pressure term adds a regularization effect to prevent the model from predicting negative values.

```python

def mse_with_positive_pressure(y_pred: torch.Tensor, y_true: torch.Tensor):
    """Custom loss function ensuring positive values."""
    mse = (y_true - y_pred) ** 2
    positive_pressure = 10 * torch.maximum(-y_pred, torch.zeros_like(y_pred))
    return torch.mean(mse + positive_pressure)

def train_model(model, train_loader, num_epochs, device, learning_rate=0.0001):
    """Train the SRU model."""
    pitch_criterion = nn.CrossEntropyLoss()
    optimizer = optim.Adam(model.parameters(), lr=learning_rate)
    
    model.train()
    history = []
    
    from tqdm import tqdm
    
    for epoch in tqdm(range(num_epochs), desc='Training epochs'):
        epoch_loss = 0
        for sequences, targets in tqdm(train_loader, desc=f'Epoch {epoch+1}', leave=False):
            sequences = sequences.to(device)
            targets = {k: v.to(device) for k, v in targets.items()}
            
            optimizer.zero_grad()
            outputs = model(sequences)
            
            pitch_loss = pitch_criterion(outputs['pitch'], 
                                       targets['pitch'].squeeze())
            step_loss = mse_with_positive_pressure(outputs['step'], 
                                                 targets['step'])
            duration_loss = mse_with_positive_pressure(outputs['duration'],
                                                     targets['duration'])
            
            total_loss = 0.05 * pitch_loss + step_loss + duration_loss
            
            total_loss.backward()
            optimizer.step()
            
            epoch_loss += total_loss.item()
            
        avg_loss = epoch_loss / len(train_loader)
        history.append(avg_loss)
        print(f'Epoch {epoch+1}/{num_epochs}, Loss: {avg_loss:.4f}')
    
    return history

```

By combining these losses, the model not only learns to predict pitch, step, and duration accurately but also ensures that the predictions respect the physical constraints of the problem.


### **3. Backward Pass (Gradient Computation)**
---

The backward pass in the SRU model involves computing gradients of the loss with respect to the model's parameters, allowing the optimizer to update the weights during training.

**1. Gradient Computation for Losses**

After calculating the total loss, which is the weighted sum of the pitch, step, and duration losses, the model uses backpropagation to compute the gradients. Specifically:

- The CrossEntropyLoss for pitch produces gradients for the output layer corresponding to pitch, guiding the model to improve its pitch predictions.
- The MSE with Positive Pressure for step and duration predictions generates gradients for the respective output layers, adjusting the model to minimize prediction errors while ensuring that the step and duration values stay positive.

**2. Backpropagation through SRU Layers**

The backpropagation process starts from the output layer, where the loss is computed, and gradients are propagated backward through the network layers. In the SRU model:

- The loss gradients are propagated through each SRUCell.
- The gradients are computed for each gate in the SRUCell (forget gate, reset gate, candidate state, and input transformation) by using the chain rule.
- Gradients are then passed backward through the sequence, updating the weights at each time step in the SRU layers.

**3. Parameter Updates**

After computing the gradients for all layers, the Adam optimizer is used to update the model's parameters. The optimizer adjusts the weights of the SRUCells and the output layers based on the computed gradients, ensuring that the model's predictions improve after each epoch.

```python
# Training loop with backward pass and optimizer step
optimizer.zero_grad()  # Reset gradients
total_loss.backward()  # Compute gradients
optimizer.step()       # Update parameters based on gradients
```

The backward() function in PyTorch automatically handles the computation of gradients for all layers. When called, it computes the gradients for the parameters by applying the chain rule, starting from the loss and moving backward through the network.


### **Step 4: Output Prediction**
---

The final hidden state is passed through:
- Pitch prediction: $$ \text{Linear}(h_t) $$ → Softmax over vocab size.
- Step and Duration prediction: $$ \text{Linear}(h_t) $$ → Regression outputs.

```python

class MusicSRU(nn.Module):
    """SRU model for music generation."""
    def __init__(self, input_size=3, hidden_size=128, vocab_size=128, num_layers=8):
        super(MusicSRU, self).__init__()
        self.hidden_size = hidden_size
        
        # Our custom SRU layer
        self.sru = SRU(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            dropout=0.1,
            bidirectional=False,
            layer_norm=True
        )
        
        # Output layers
        self.pitch_layer = nn.Linear(hidden_size, vocab_size)
        self.step_layer = nn.Linear(hidden_size, 1)
        self.duration_layer = nn.Linear(hidden_size, 1)
        
    def forward(self, x):
        # SRU expects input of shape (seq_len, batch, input_size)
        x = x.transpose(0, 1)
        output, _ = self.sru(x)
        
        # Get the last output
        last_output = output[-1]
        
        pitch = self.pitch_layer(last_output)
        step = self.step_layer(last_output)
        duration = self.duration_layer(last_output)
        
        return {
            'pitch': pitch,
            'step': step,
            'duration': duration
        }

```

Now, we take a step further by incorporating Long Short-Term Memory (LSTM) networks, bidirectionality, and attention mechanisms to enhance expressiveness and contextual understanding.

## **Understanding the RNN-LSTM Model**

The EnhancedMusicRNN model was further implemented for music generation. It consists of the following components:

- **LSTM Layer:**
  - Processes sequences bidirectionally to enhance temporal context understanding.
  - Computes hidden states using:
  
    $$ f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f) $$

    $$ i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) $$

    $$ \tilde{c}_t = \tanh(W_c x_t + U_c h_{t-1} + b_c) $$

    $$ c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t $$

    $$ o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) $$

    $$ h_t = o_t \odot \tanh(c_t) $$
  
- **Multihead Attention:**
  - Computes attention weights over hidden states:

    $$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V $$

  - Improves the model's ability to focus on key parts of the sequence.

- **Feedforward Network with Residual Connections:**
  - Uses multiple layers for better expressiveness:
     
     $$ h' = \text{ReLU}(W h + b) $$

     $$ h'' = \text{ReLU}(W' h' + b') $$

     $$ ∆ h = h'' + h' (Residual connection) $$
     
     $$ y = W_{	ext{out}} h'' + b_{	ext{out}} $$


### **Forward Pass**
---

During the forward pass:

1. The input sequence is fed into the bidirectional LSTM layer.
2. The hidden states are passed to the attention mechanism, which refines them by weighting important time steps.
3. The attention-refined outputs go through a stack of fully connected layers with residual connections.
4. The final output is generated, representing the predicted music sequence.


```python

class EnhancedMusicRNN(nn.Module):
    """Enhanced RNN model for music generation with more expressive capabilities."""
    
    def __init__(self, input_size, hidden_size, num_layers, output_size, dropout=0.2):

        super(EnhancedMusicRNN, self).__init__()
        
        self.hidden_size = hidden_size
        self.num_layers = num_layers
        
        # Bidirectional LSTM for better context understanding
        self.lstm = nn.LSTM(
            input_size, 
            hidden_size, 
            num_layers, 
            batch_first=True, 
            dropout=dropout if num_layers > 1 else 0,
            bidirectional=True
        )
        
        # Attention mechanism
        self.attention = nn.MultiheadAttention(
            embed_dim=hidden_size * 2,  # *2 for bidirectional
            num_heads=4,
            dropout=dropout
        )
        
        # Multiple fully connected layers with residual connections
        self.fc1 = nn.Linear(hidden_size * 2, hidden_size)
        self.fc2 = nn.Linear(hidden_size, hidden_size)
        self.fc3 = nn.Linear(hidden_size, output_size)
        
        self.dropout = nn.Dropout(dropout)
        self.relu = nn.ReLU()
        
    def forward(self, x, hidden=None):

        batch_size = x.size(0)
        seq_length = x.size(1)
        
        # Initialize hidden state if not provided
        if hidden is None:
            h0 = torch.zeros(self.num_layers * 2, batch_size, self.hidden_size).to(x.device)
            c0 = torch.zeros(self.num_layers * 2, batch_size, self.hidden_size).to(x.device)
            hidden = (h0, c0)
        
        # LSTM forward
        lstm_out, hidden = self.lstm(x, hidden)
        
        # Apply attention
        # Reshape for attention: [seq_length, batch_size, hidden_size*2]
        lstm_out_for_attn = lstm_out.permute(1, 0, 2)
        attn_out, _ = self.attention(lstm_out_for_attn, lstm_out_for_attn, lstm_out_for_attn)
        
        # Reshape back: [batch_size, seq_length, hidden_size*2]
        attn_out = attn_out.permute(1, 0, 2)
        
        # Get the last output for prediction
        if seq_length > 1:
            out = attn_out[:, -1, :]
        else:
            out = attn_out.squeeze(1)
        
        # Fully connected layers with residual connections
        fc1_out = self.relu(self.fc1(out))
        fc1_out = self.dropout(fc1_out)
        
        fc2_out = self.relu(self.fc2(fc1_out))
        fc2_out = self.dropout(fc2_out)
        
        # Residual connection
        fc2_out = fc2_out + fc1_out
        
        # Final output layer
        output = self.fc3(fc2_out)
        
        return output, hidden
```


### **Backward Pass**
---

The training process involves optimizing the model using backpropagation. The steps include:
1. **Compute Loss:** The mean squared error (MSE) loss is computed:

   $$ \mathcal{L} = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2 $$

2. **Gradient Calculation:** Gradients are computed for each parameter using the chain rule.

3. **Gradient Clipping:** To prevent exploding gradients:

   $$ \theta = \min(\theta, \text{clip\_value}) $$

4. **Parameter Update:** Using Adam optimizer:

   $$ \theta = \theta - \eta \frac{m_t}{\sqrt{v_t} + \epsilon} $$


The model was trained using the Mean Squared Error (MSE) loss function, which computes the average squared difference between the predicted and target values. During the training process, gradient clipping was applied by setting a maximum gradient norm of 1.0 using `torch.nn.utils.clip_grad_norm_` to prevent gradient explosion and ensure training stability.

The Adam optimizer was used, which adapts the learning rate for each parameter during training. A learning rate scheduler was also implemented using `ReduceLROnPlateau`, which reduces the learning rate by a factor of 0.5 when the validation loss plateaus for 5 epochs. This adaptive approach helps improve convergence by dynamically adjusting the learning rate to avoid overshooting during optimization.

This approach resulted in improved sequence prediction with reduced training loss and better generalization.
